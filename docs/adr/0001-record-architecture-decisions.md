# ADR-0001: Record architecture decisions

Status: Accepted

## Context

This multi-phase project needs durable decisions separate from chat history.

## Decision

Record significant choices as numbered ADRs with status, context, decision and
consequences. Mark unverified choices Proposed; supersede rather than silently
rewrite accepted decisions. Update the plan when decisions change.

## Consequences

The initial decisions are ADR-0002 through ADR-0008. Revisit proposed API and FIT
choices after the discovery spike, not during foundation work.
